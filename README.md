# Agent Skills

This repository contains reusable skills for AI agents. Skills are intended to be agent-agnostic and are organized in their own directories.

## Skills

- **delegate-local-tasks** — Guides agents in delegating bounded evidence and implementation tasks to local Ollama models, then verifying the evidence and proposals and running acceptance checks. See [the skill documentation](./delegate-local-tasks/SKILL.md).

## Installation

See [the installation instructions](./docs/install.md) for installing all
skills or an individual skill into an agents home directory.
